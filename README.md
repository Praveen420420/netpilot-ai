# NetPilot AI 🌐

**An AI-powered network planning and troubleshooting assistant.**

NetPilot AI is a prototype designed to help students, IT support professionals, and small businesses plan office networks and understand common networking problems.

## Features

- **Network Planner:** Create a draft network plan based on device requirements.
- **IPv4 Subnet Calculator:** Calculate subnet details from an IP address and CIDR prefix.
- **Network Troubleshooter:** Follow guided steps to investigate common connectivity issues.
- **Security Checklist:** Review basic network security practices.
- **PDF Reports:** Generate reports for network plans and documentation.
- **AI Assistant:** Ask networking questions and receive explanations powered by Google Gemini.

## Technologies

- HTML
- CSS
- JavaScript
- Google Gemini
- Hatchable

## Example Use Case

Plan a small office network containing:
- 10 PCs
- 4 CCTV cameras
- 1 server
- 15 Wi-Fi devices

The planner helps organize devices into suggested network segments and provides a starting point for network design.

## Project Status

This project is a work in progress. Network recommendations are planning guidance, not a substitute for validating the design, configuring network equipment, or performing a professional security assessment.

## Developer

Created as a hands-on learning project focused on networking, troubleshooting, and AI-assisted IT tools.

## Disclaimer

Verify all generated network plans and security recommendations before using them in a production environment.
